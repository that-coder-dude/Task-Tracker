# 📝 Task Tracker

Task Tracker is a full-stack web application that allows users to manage their tasks by creating projects, adding tasks under each project, and performing CRUD operations (Create, Read, Update, Delete) on tasks. It also supports task status tracking and timestamps for creation and completion.

---

## 🚀 Features

- User Signup and Login (with authentication)
- Project Creation and Viewing
- Task Creation, Editing, Deletion
- Toggle Task Completion
- Task Statuses: Not Started, In Progress, Completed
- View task creation and completion times
- Responsive and clean frontend using React

---

## 🛠️ Tech Stack

**Frontend:**
- React (Vite)
- React Router DOM
- Axios

**Backend (Assumed/Required):**
- Node.js
- Express.js
- MongoDB / Mongoose

---

## 🔧 Setup Instructions

### Prerequisites

- Node.js and npm installed
- MongoDB running (locally or cloud-based)
- Backend server ready and running (API endpoints should match frontend usage)
